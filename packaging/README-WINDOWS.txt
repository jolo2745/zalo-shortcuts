ZALO SHORTCUTS 0.4.0 - WINDOWS

1. Open ZaloShortcuts.exe.
2. Follow the setup guide that appears the first time. Leave automatic startup
   checked so the helper is ready whenever you sign into Windows.
3. In Zalo Desktop, type / plus all or part of the shortcut and press Tab.
4. The message is inserted. Press Enter normally when you are ready to send it.

Automatic startup runs the helper quietly in the system tray. It can be turned
off later from the app's Setup guide or Windows Settings > Apps > Startup.
Administrator permission is not required for this per-user setting.

Windows SmartScreen may warn because this early build is not code-signed.
Choose More info > Run anyway only if you received this file from a source you trust.

Messages are stored locally. There is no account, cloud service, automatic
translation, or automatic sending.
