ZALO SHORTCUTS 0.4.0 - MAC

Choose the correct download:
- arm64: Apple silicon Macs (M1, M2, M3, M4, M5, and newer)
- x64: Intel Macs

1. Extract the ZIP and move Zalo Shortcuts.app to Applications.
2. Open the app.
3. Follow the setup guide. It opens System Settings > Privacy & Security >
   Accessibility automatically.
4. Turn on Zalo Shortcuts. The guide detects the permission without requiring a
   manual restart.
5. Leave automatic startup checked so the helper is ready whenever you sign
   into your Mac.
6. In Zalo Desktop, type / plus all or part of the shortcut and press Tab.
7. The message is inserted. Press Enter normally when you are ready to send it.

Automatic startup runs the helper quietly in the menu bar. On macOS 13 or newer,
approve Zalo Shortcuts under System Settings > General > Login Items if asked.
It can be turned off later from the app's Setup guide or Login Items.

This early build is not signed or notarized with an Apple Developer certificate,
so macOS may block the first launch. It should be signed and notarized before
public distribution.

Messages are stored locally. There is no account, cloud service, automatic
translation, or automatic sending.
